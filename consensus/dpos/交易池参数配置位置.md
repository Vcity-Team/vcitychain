# 交易池参数配置位置

## 参数配置流程

### 1. `--max-enqueued` 参数配置位置

#### 命令行参数定义
**文件**：`command/server/server.go`

**位置**：第181-186行
```go
cmd.Flags().Uint64Var(
    &params.rawConfig.TxPool.MaxAccountEnqueued,
    maxEnqueuedFlag,  // "max-enqueued"
    defaultConfig.TxPool.MaxAccountEnqueued,  // 默认值128
    "maximum number of enqueued transactions per account",
)
```

#### 默认值定义
**文件**：`command/server/config/config.go`

**位置**：第151行
```go
MaxAccountEnqueued: 128,  // 默认值
```

#### 参数传递
**文件**：`command/server/params.go`

**位置**：第225行
```go
MaxAccountEnqueued: p.rawConfig.TxPool.MaxAccountEnqueued,
```

#### 实际使用
**文件**：`server/server.go`

**位置**：第588行
```go
MaxAccountEnqueued: m.config.MaxAccountEnqueued,
```

#### 最终应用
**文件**：`txpool/txpool.go`

**位置**：第216行
```go
maxEnqueuedLimit: config.MaxAccountEnqueued,
```

**使用位置**：第991行
```go
if account.enqueued.length() == account.maxEnqueued && tx.Nonce != accountNonce {
    return ErrMaxEnqueuedLimitReached
}
```

## 配置方式

### 方式1：命令行参数（推荐）

```bash
./polygon-edge server \
  --max-enqueued 1024 \
  --max-slots 16384 \
  [其他参数...]
```

### 方式2：配置文件

**文件**：`node-config-validator.yaml` 或配置文件

```yaml
tx_pool:
  max_account_enqueued: 1024
  max_slots: 16384
```

**注意**：需要确认配置文件是否支持这些字段。

### 方式3：修改默认值（代码级别）

**文件**：`command/server/config/config.go`

**位置**：第150-151行
```go
TxPool: &TxPool{
    PriceLimit:         0,
    MaxSlots:           16384,        // 修改默认值
    MaxAccountEnqueued: 1024,         // 修改默认值
},
```

## 修改建议

### 快速修改（推荐）

使用命令行参数：
```bash
--max-enqueued 1024
--max-slots 16384
```

### 永久修改默认值

修改 `command/server/config/config.go` 第150-151行：

```go
TxPool: &TxPool{
    PriceLimit:         0,
    MaxSlots:           16384,        // 从4096改为16384
    MaxAccountEnqueued: 1024,         // 从128改为1024
},
```

这样即使不传命令行参数，也会使用新的默认值。

## 验证配置是否生效

### 方法1：查看日志

启动时查看日志，应该会显示交易池配置信息。

### 方法2：测试

发送超过128个交易（如果使用默认值），应该会看到 `ErrMaxEnqueuedLimitReached` 错误。
发送超过1024个交易（如果使用新值），才会看到错误。

### 方法3：RPC接口

使用RPC接口查看交易池状态：
```bash
curl -X POST http://127.0.0.1:8545 \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"txpool_content","params":[],"id":1}'
```
